In short

popguia is an open source project for creating popups that talk with the visitor: instead of asking for the email right away, it asks two or three questions, teaches something useful and points to the right product, course or content. It is for anyone with a site (HTML, Next.js, Astro, WordPress) who uses a coding agent such as Claude Code, Codex or Cursor: the agent installs it, writes the journeys and tracks the results. It is free, MIT licensed, with no subscription and no server of ours. Today the repository has the research and the plan; the code is still to be written.

What it is

The Alia Popups idea, open and for any site

Alia showed that interactive journeys convert better than the discount popup, but it works only on Shopify and charges per visitor. popguia brings the same technique to any site, for free.

🤖 Installed by the agent

A CLI (npx popguia init), an MCP server and a skill teach your agent to detect the site, add the script and create the journeys.

📁 Everything in files

Journeys, experiments and weights live as JSON inside your repository. You can review them in git, undo them and version them like code.

📈 Learns by itself

Control group, A/B testing and then an algorithm (Thompson sampling) that sends more visitors to the version that works best.

How it works

From the request to the agent to the journey that optimizes itself

The variant texts are written by the user's own agent: the MCP delivers the instructions and the format, without calling any paid API of ours.

You ask the agent→ detectar_site→ instalar_snippet→ criar_jornada→ gerar_variantes→ validate + preview→ publish→ measure and optimize

Light widget

Target of up to 15 KB (gzip), accessible <dialog>, no layout shift (CLS 0) and no modal on entry on mobile.

Smart triggers

Time, scroll, exit intent, inactivity and click, with a frequency cap and a pause after closing.

Your collection, not ours

Events go to the Umami, PostHog or GA4 you already use, or to a collector you publish yourself on your Cloudflare account.

User guide · step by step

How it will work in practice

Note: the commands below are the design of the plan (docs/03 (in Portuguese)). The packages have not been published to npm yet. For now, what you can do is read the research and the plan.

1

Read the research and the plan (available now)

Market, open source projects, AI-driven install, architecture, algorithms and compliance.

git clone https://github.com/inematds/popguia
cd popguia && cat PLANO.md
2

Ask the agent (planned)

A single prompt. The agent reads setup.md, adds the skill and the MCP and carries on by itself.

# in Claude Code, inside your site folder
"Read https://inematds.github.io/popguia/setup.md and install a 3-question
quiz that recommends the right product to each visitor."
3

Install the script (planned)

The CLI detects the framework, shows the diff first and only touches one layout file and the popguia/ folder.

npx popguia init --dry-run   # shows what will change
npx popguia init             # applies
4

Create and validate a journey (planned)

Ready-made templates: diagnostic, educational quiz, Learn & Earn, micro-commitment and 2-step newsletter.

npx popguia add jornada --template diagnostico
npx popguia validate          # schema, accessibility, LGPD/GDPR
npx popguia preview
5

Measure and optimize (planned)

Report with a control group; the optimizer only changes the weights when there is enough data.

npx popguia report --html > report.html
npx popguia optimize --experimento welcome-titulo
npx popguia doctor https://your-site.com
Journeys

Three demo sites

The plan validates popguia on fictional sites inside the repository itself, published on GitHub Pages. They are yet to be built.

🎓 School (HTML)

3 questions about goal and level and a recommendation of the 3 best-fitting courses from a fictional catalog.

🛍️ Store (Next.js)

Learn & Earn: the visitor learns about the product, reveals a coupon and leaves their email in two steps.

📝 Blog (Astro)

2-step newsletter with a scroll or exit trigger, frequency cap and a mobile version.
